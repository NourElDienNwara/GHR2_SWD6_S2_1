# Digital Egypt Pioneers Initiative (DEPI) - Software Testing Graduation Project

This repository contains the final graduation project for the **Digital Egypt Pioneers** initiative.  
Our team focused on applying both **Manual Testing** and **Automation Testing** techniques to ensure the quality and reliability of a selected web application.

## 🧪 Project Overview

- **Project Title:** Web Application Testing using Manual and Automation Techniques  
- **Track:** Software Testing  
- **Initiative:** Digital Egypt Pioneers Initiative (DEPI) – Ministry of Communications and Information Technology (MCIT), Egypt  
- **Team Size:** 5 members  
- **Project Type:** Graduation Project  

We selected a real-world e-commerce website as our testing subject. Our work includes:

- Detailed manual test cases  
- Bug reporting with severity and priority levels  
- Automation scripts for core functionalities using tools like **Selenium WebDriver**

---

## 📋 Manual Testing Artifacts

- ✅ Test Plan  
- ✅ Test Scenarios  
- ✅ Test Cases (positive and negative)  
- ✅ Bug Reports with screenshots  
- ✅ Traceability Matrix  
- ✅ Test Summary Report  

All documents are available inside the `/manual-testing/` folder.

## 🤖 Automation Testing Artifacts

- ✅ Selenium WebDriver scripts (Java)  
- ✅ Page Object Model (POM) design pattern   
- ✅ Automated Test Reports (HTML/XML)  
- ✅ Screenshots on failure  

All scripts and reports are stored in the `/automation-testing/` folder.
